# Goodreads clone UI

This test asks a model to turn a short product brief into a responsive frontend for a self-hosted Goodreads clone. The app should use HTML, CSS, and JavaScript, with its data and behavior mocked for now.

[Read the exact prompt](prompt.md)

## What to assess

- How clearly the interface supports a book-focused experience.
- Whether the layout works at both desktop and mobile sizes.
- Whether mocked content and interactions make the UI usable without a backend.
- Whether the delivered files can be inspected and run locally.

The prompt leaves the feature set and visual direction open so each model's choices are part of the result.
